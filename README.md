# LoopBound: Paradox

## Game Description

**LoopBound: Paradox** is a 2D sci-fi time-loop puzzle platformer game created using the **iGraphics** library in C/C++. The project demonstrates basic graphics programming concepts like drawing shapes, handling user input, time-loop mechanics, and animations.

## Features
- Multiple playable characters (PEX and Hero).
- Time-loop mechanism with recording and playback of clones.
- Switches, laser gates, and exit portals for puzzle solving.
- Keyboard controls for movement, jumping, and rewinding.
- Dynamic level select and interactive menus.



## Project Details
IDE: Visual Studio 2013

Language: C, C++.

Platform : Windows PC.

Genre : 2D Sci-Fi Time-Loop Puzzle Platformer


## How to Run the Project

Make sure you have the following installed:
- **Visual Studio 2013**
- **MinGW Compiler** (if needed)
- **iGraphics Library** (included in this repository)


Open the project in Visual Studio 2013
- Open Visual Studio 2013.
- Go to File → Open → Project/Solution.
- Locate and select the .sln file from the cloned repository.
- Click Build → Build Solution
- Run the program by clicking Debug → Start Without Debugging


## How to Play

### **Controls**
| Action       | Key / Control |
|-------------|----------|
| **Move & Jump** | `ARROWS` / `WASD` |
| **Rewind** | `R` |
| **Menu** | `ESC` |


### **Game Rules**

- Complete levels within the given time limit.
- Utilize temporal clones and switches to unlock portals.
- Avoid hazards and lasers across multiple loops.
